# MurText 0.2.0 — ядро парсера для MurCMS

MurText — компактный язык управляемой разметки для подготовки содержимого страниц, сниппетов и других текстовых полей MurCMS.

Ядро предназначено для доверенных пользователей: разработчиков, администраторов и контент-менеджеров с доступом к редактированию сайта. Это не парсер публичных комментариев и не HTML-санитайзер для недоверенного ввода.

## Статус версии

Версия `0.2.0` — актуальная версия ядра, используемая плагином MurText 0.2.3. Грамматика и публичный API ядра в update-релизе 0.2.1 не изменялись.

В неё входят:

- автоматические и явные абзацы;
- заголовки `h1`–`h6` и Markdown-заголовки;
- курсив, полужирный текст, код, выделение, клавиши и зачёркивание;
- классы, inline-style, `id` и произвольные HTML-атрибуты;
- блочные элементы и вложенность;
- сокращённый однострочный `div`;
- параллельное открытие и закрытие блоков через `||`;
- цитаты;
- маркированные, нумерованные, вложенные и TODO-списки;
- компактные и подробные таблицы;
- ссылки, изображения и изображения-ссылки;
- `details` и `details+`;
- fenced-блоки кода;
- `raw`, `nomurtext`, защита `script` и `style`;
- диагностика незакрытых и неправильно закрытых блоков;
- строгая проверка для редактора;
- компактный и читаемый HTML-вывод.

Не входят в эту сборку:

- конвертер Simple → MurText;
- обратная совместимость с Simple и TextSimple;
- пользовательские директивы `gallery`, `snippet`, `component`;
- публичный профиль безопасности.

## Требования

- целевая платформа: PHP 8.5;
- Composer не требуется;
- сторонние библиотеки не требуются;
- код не содержит логики поддержки старых версий PHP.

Ядро разделено на небольшое число файлов. Отдельные классы существуют только там, где у них есть самостоятельная ответственность:

- `parser.php` — общий процесс разбора;
- `block_parser.php` — блочная структура документа;
- `list_parser.php` — автоматические и вложенные списки;
- `inline_parser.php` — строчная разметка;
- `attribute_parser.php` — классы, стили, `id`, атрибуты;
- `parse_result.php` — результат и диагностика;
- `murtext.php` — публичная точка входа.

## Подключение

```php
<?php

declare(strict_types=1);

require_once __DIR__ . '/murtext/murtext.php';

use MurCMS\MurText\MurText;

$source = <<<'MURTEXT'
h2(section-title) Заголовок

**Жирное начало**, затем обычный текст.
MURTEXT;

$html = MurText::toHtml($source);

echo $html;
```

## Основной API

### Получить полный результат

```php
$result = MurText::parse($source, [
    'pretty' => false,
    'site_url' => 'https://example.com',
    'uploads_url' => 'https://example.com/uploads',
    'pages_url' => 'https://example.com/pages',
]);

$html = $result->html;
$warnings = $result->warnings;
$errors = $result->errors;
```

### Получить только HTML

```php
$html = MurText::toHtml($source);
```

### Строгая проверка для редактора

```php
$result = MurText::validate($source);

if (!$result->isValid()) {
    foreach ($result->errors as $error) {
        echo $error->line . ': ' . $error->message;
    }
}
```

`validate()` включает читаемый HTML и переводит структурные предупреждения в ошибки проверки.

## Настройки

```php
$options = [
    'pretty' => false,
    'strict' => false,
    'site_url' => '',
    'uploads_url' => '',
    'pages_url' => '',
];
```

### `pretty`

- `false` — более компактный HTML для сайта;
- `true` — HTML с переносами строк для предпросмотра и диагностики.

### `strict`

При `true` незакрытые блоки, повреждённая вложенность и неверные метаданные дополнительно попадают в список ошибок.

### URL-настройки

Используются для сокращений:

```text
##contacts
//photo.webp
site:contacts
uploads:photo.webp
pages:document.pdf
```

## Абзацы

Абзацы разделяются пустой строкой.

```text
Первая строка одного абзаца.
Продолжение того же абзаца.

Второй абзац.
```

```html
<p>Первая строка одного абзаца.
Продолжение того же абзаца.</p>
<p>Второй абзац.</p>
```

Явный абзац:

```text
_ Текст
_(lead) Абзац с классом
_(lead)(color: red) Абзац с классом и стилем
```

## Принудительный перенос `<br>`

Поддерживаются три варианта.

Отдельная строка:

```text
Первая строка.
br
Вторая строка.
```

Два пробела в конце строки:

```text
Первая строка.  
Вторая строка.
```

Обратный слеш в конце:

```text
Первая строка.\
Вторая строка.
```

## Заголовки

```text
h1 Заголовок
h2 Заголовок
h3 Заголовок
h4 Заголовок
h5 Заголовок
h6 Заголовок
```

Также поддерживаются:

```text
# H1
## H2
### H3
```

MurText не создаёт автоматические `id`.

```text
h2(section-title)#delivery Доставка
h2(section-title){id="delivery"} Доставка
```

## Строчная разметка

```text
*курсив*
_курсив_

**полужирный**
__полужирный__

***полужирный курсив***

`код`
~~зачёркнутый текст~~
@выделенный текст@
@@Ctrl+S@@
```

Рекомендуемый стиль:

```text
*курсив*
**полужирный**
```

Технические имена не изменяются:

```text
site_root_auditor
parser_murtext
content_page_id
```

## Экранирование

Обратная косая черта выводит служебный символ буквально:

```text
\*не курсив\*
\_не курсив\_
\@не mark\@
\`не code\`
\# не заголовок
\- не список
```

## Классы, стили, ID и атрибуты

Порядок метаданных:

```text
команда(классы)(стили)#id{атрибуты}
```

Пример:

```text
section(content-block wide)(color: var(--primary500))#delivery{data-section="delivery" aria-label="Доставка"}
    Текст
/section
```

CSS-функции со скобками внутри style поддерживаются:

```text
_(lead)(color: var(--primary500); width: calc(100% - 20px)) Текст
```

## Однострочный DIV

```text
__ Текст
__(notice) Текст
```

Отличие от полужирного текста:

```text
__ Текст блока
__полужирный текст__
```

Пробел после первых двух подчёркиваний обозначает `div`.

```text

nav
```

Пример:


```text

    Текст

```

## Цитаты

```text
> Первая строка
> Вторая строка
```

Соседние строки объединяются через `<br>`.

Класс:

```text
>(notice) Текст цитаты
```

Другие формы:

```text
bqq Цитата

blockquote
    Многострочная цитата
/blockquote
```

## Списки

Маркированный список:

```text
- Первый
- Второй
- Третий
```

Нумерованный:

```text
1. Первый
2. Второй
3. Третий
```

Вложенность — два пробела на уровень:

```text
- Первый уровень
  - Второй уровень
    - Третий уровень
```

Продолжение пункта:

```text
- Длинный пункт,
  который продолжается на следующей строке.
```

TODO:

```text
- [x] Выполнено
- [ ] Не выполнено
```

Явная форма:

```text
ul(marker-square)
- Первый
- Второй
/ul
```

## Raw-контент

Основной вариант:

```text
raw
<div class="custom">**MurText здесь не работает**</div>
/raw
```

Альтернатива:

```html
<!-- nomurtext -->
<div class="custom">Исходный HTML</div>
<!-- /nomurtext -->
```

Содержимое `<script>` и `<style>` автоматически защищается от MurText-разметки.

Для сложного многострочного ручного HTML рекомендуется `raw`.

## HTML и квадратные коды

Обычные HTML-теги сохраняются. MurText предназначен для доверенного редактора, поэтому raw HTML не запрещается.

Обрабатываются только однозначные ссылки и изображения:

```text
[Текст](url)
![Alt](url)
!![Alt](url)
```

Другие квадратные конструкции сохраняются для последующей обработки MurCMS или BBCode-парсером:

```text
[list]
[gallery]
[snippet name="contacts"]
[b]Текст[/b]
```

## Диагностика

MurText старается не разрушать страницу при ошибке.

Если блок не закрыт:

```text
section
    Текст
```

он будет закрыт автоматически, а результат получит предупреждение:

```text
Unclosed block <section> was closed at end of document.
```

Если закрывающая команда нарушает вложенность, внутренние блоки закрываются автоматически с предупреждением.

Неизвестная команда считается обычным текстом. Неизвестная закрывающая команда также сохраняется как текст и создаёт предупреждение.

```php

    'paragraph_mode' => 'blank_lines', // blank_lines | line
```

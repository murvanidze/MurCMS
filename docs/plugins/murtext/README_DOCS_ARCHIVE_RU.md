# Документация MurText 0.2.3

Этот каталог является частью общего documentation package MurCMS и содержит документацию плагина MurText.

Состав:

- `README_RU.md` — установка, конфигурация, update-safe модель и работа плагина;
- `CORE_README_RU.md` — синтаксис и поведение parser core 0.2.0;
- `AI_INSTRUCTION_RU.md` — автономная инструкция для ИИ по подготовке контента в MurText;
- `RELEASE_PACKAGE_RU.md` — состав production/documentation/source-пакетов.

Runtime-плагин не зависит от этих файлов. На рабочем сайте документация может отсутствовать в папке плагина.

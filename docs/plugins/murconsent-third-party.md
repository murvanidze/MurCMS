# Сторонние компоненты

Дата: 2026-09-07  
Статус: актуально для MurConsent `1.0.3`

MurConsent 1.0.3 не включает стороннюю runtime-библиотеку управления cookies, JavaScript framework, иконочный шрифт или удалённый asset.

В частности, в пакет не входят:

- CookieConsent v3;
- Klaro;
- jQuery;
- Font Awesome;
- Google-hosted fonts;
- внешние CSS/JS CDN.

Иконка шестерёнки является собственным inline SVG, собранным из геометрических примитивов. Она не копирует и не встраивает файл Font Awesome.

Скрипты Google и изображение Flag Counter создаются только как явно настроенные внешние сервисы после соответствующего согласия посетителя.

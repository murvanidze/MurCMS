# Установка и обновление MurConsent

Дата: 2026-09-07  
Статус: актуальная инструкция MurConsent `1.0.3` для MurCMS `0.4.2`

## Требования

- MurCMS `0.4.2`;
- PHP 8.5+ (host requirement MurCMS 0.4.2);
- включённый JavaScript в браузере посетителя;
- HTTPS для установки cookie с флагом `Secure`;
- права записи PHP в `data/config/` и `data/storage/backups/`.

## Новая установка

1. Распакуйте архив поверх каталога проекта, в котором находится папка `root`.
2. Проверьте появление каталогов:

   ```text
   root/murcms/plugins/murconsent/
   root/murcms/assets/plugins/murconsent/
   ```

3. Войдите в MurCMS и откройте `/admin/plugins`.
4. Включите plugin ID `murconsent`.
5. Откройте `/admin/plugin/murconsent`.
6. Сохраните основные настройки. Рабочий файл будет создан как:

   ```text
   root/data/config/murconsent.php
   ```

7. Настройте сервисы и удалите их старые вставки из других мест сайта.

Если `data/config/murconsent.php` отсутствует, но существует legacy
`data/config/privacy-consent.php`, MurConsent предварительно загружает совместимые старые значения
в форму. Сохраните настройки, чтобы создать новый `murconsent.php`. Legacy-файл не является новым
runtime source of truth.

## Обновление

При обновлении копируются:

```text
root/murcms/plugins/murconsent/
root/murcms/assets/plugins/murconsent/
root/data/config/murconsent.dist.php
```

Не заменяйте существующий:

```text
root/data/config/murconsent.php
```

Плагин объединяет отсутствующие параметры с текущими defaults, поэтому рабочий конфиг можно обновлять через административную форму. Версия plugin code определяется `Plugin::VERSION` и в текущем root равна `1.0.3`.

## Проверка после установки

В чистом профиле браузера:

1. Очистите cookies и storage домена.
2. Откройте DevTools → Network.
3. Перезагрузите страницу.
4. До выбора не должно быть запросов к Google и Flag Counter.
5. Нажмите «Отклонить все» — запросы не должны появиться после перезагрузки.
6. Разрешите только аналитику — должен загрузиться только аналитический канал.
7. Разрешите маркетинг — должны загрузиться только соответствующие настроенные интеграции.
8. Отзовите ранее выданное согласие и проверьте перезагрузку/удаление доступных cookies.
9. Проверьте RU, RO и EN: язык баннера должен соответствовать текущей странице, а выбор оставаться общим для домена.
10. Проверьте Google Tag Assistant с реальными ID.

## Откат

1. Отключите `murconsent` через `/admin/plugins`.
2. При необходимости восстановите одну из копий:

   ```text
   root/data/storage/backups/murconsent/
   ```

3. Удаление каталога плагина не удаляет consent cookie у уже посетивших сайт. Её можно удалить вручную или оставить до истечения срока.

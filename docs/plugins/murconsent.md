# MurConsent 1.0.3 для MurCMS

Дата: 2026-09-07  
Статус: актуальная документация MurConsent `1.0.3` для MurCMS `0.4.1`

**Автор продукта:** Alex Murvanidze  
**Совместимость:** MurCMS 0.4.1  
**ID плагина:** `murconsent`

MurConsent — автономный плагин управления согласием для MurCMS. Он разработан на основе функциональной модели проверенного плагина Consenta 1.2.0 для MaxSite CMS, но реализован нативно для архитектуры MurCMS: через Plugin API, hooks, административные роли, CSRF, файловую конфигурацию и резервные копии.

## Главный принцип

До соответствующего положительного выбора посетителя MurConsent:

- не создаёт `gtag.js`;
- не создаёт и не загружает контейнер Google Tag Manager;
- не инициализирует Google Analytics 4;
- не инициализирует Google Ads и измерение конверсий;
- не вставляет активный HTML Flag Counter;
- не создаёт `dataLayer` только ради предварительной передачи cookieless-сигналов;
- не ставит необязательные события в очередь для последующей отправки.

Используется собственная строгая предварительная блокировка. Advanced Consent Mode и cookieless pings до согласия не применяются.

## Категории

- **Необходимые** — всегда включены; содержат cookie выбора MurConsent и другие описанные администратором технически необходимые операции.
- **Аналитика** — прямой GA4 и/или аналитические теги в GTM.
- **Маркетинг и измерение конверсий** — прямой Google Ads и/или рекламные и конверсионные теги в GTM.
- **Внешняя статистика** — Flag Counter.

`ad_personalization` всегда остаётся `denied`. Персонализированная реклама и ремаркетинг не включаются автоматически.

## Основные возможности

- независимые переключатели прямого GA4, прямого Google Ads и GTM;
- одновременная работа собственного GA4 и отдельного рекламного GTM;
- обязательная классификация GTM: аналитика, маркетинг либо обе категории;
- отдельное согласие на Flag Counter;
- RU, RO и EN на одном многоязычном сайте;
- отдельный URL политики для каждой языковой версии;
- редактирование заголовка и текста баннера по каждому языку;
- редактирование категории необходимых cookie и до 10 технических записей на язык;
- безопасный предпросмотр только для авторизованного администратора;
- тестовый режим без сохранения cookie и без загрузки сервисов;
- отзыв согласия и попытка удалить доступные first-party cookies Google;
- автоматическая ссылка настроек в footer либо ручная ссылка в шаблоне;
- JavaScript API для событий и конверсий;
- диагностика конфликтов, неверных ID, жёстко вставленных трекеров и старого плагина;
- атомарное сохранение `data/config/murconsent.php`;
- до пяти резервных копий конфигурации в `data/storage/backups/murconsent/`;
- локальные CSS и JavaScript без CDN, jQuery, внешних шрифтов и Font Awesome;
- собственная solid SVG-шестерёнка, встроенная в HTML интерфейса.

## Установка

1. Сделайте резервную копию сайта.
2. Распакуйте архив поверх корня установки MurCMS. Он добавляет только:

   ```text
   root/murcms/plugins/murconsent/
   root/murcms/assets/plugins/murconsent/
   root/data/config/murconsent.dist.php
   ```

3. Откройте `/admin/plugins` и убедитесь, что `murconsent` включён.
4. Откройте `/admin/plugin/murconsent`.
5. Настройте URL политик RU/RO/EN и нужные интеграции.
6. Удалите старые прямые вставки GA4, Ads, GTM и Flag Counter из шаблона, snippets, «ушек» и других плагинов.
7. Сначала проверьте интерфейс в тестовом режиме, затем выключите тестовый режим и выполните сетевую проверку в чистом профиле браузера.

Пакет **не содержит** рабочего `murconsent.php`, поэтому обновление плагина не перезаписывает настройки конкретного сайта. При первом сохранении файл создаётся автоматически из формы.

## Интеграции Google

### GA4 напрямую

Включите GA4 и задайте Measurement ID вида:

```text
G-XXXXXXXXXX
```

Скрипт загружается только после согласия на аналитику.

### Google Ads напрямую

Включите Google Ads и задайте Conversion ID:

```text
AW-123456789
```

Conversion Label можно указать глобально либо передавать отдельно при событии. Прямой Google Ads загружается только после согласия на маркетинг.

### Google Tag Manager

Включите GTM, задайте Container ID:

```text
GTM-XXXXXXX
```

Затем обязательно отметьте, какие цели обслуживает контейнер:

- аналитические теги;
- рекламные или конверсионные теги;
- обе категории.

До загрузки GTM MurConsent помещает в `dataLayer`:

```text
murconsent_analytics
murconsent_marketing
murconsent_flag_counter
```

и событие:

```text
murconsent_ready
```

Теги внутри GTM должны дополнительно учитывать эти значения и не дублировать прямые интеграции.

## Flag Counter

В административное поле вставляется стандартная безопасная конструкция Flag Counter: одна ссылка и одно изображение с доменов `flagcounter.com`.

В нужном месте шаблона или footer-блока добавьте:

```html
<div data-murconsent-flag-counter></div>
```

До согласия контейнер остаётся пустым, поэтому изображение не запрашивается. Заполняется только первая найденная точка вывода, чтобы не создавать двойной подсчёт.

## Ссылка настроек

Автоматическую ссылку можно включить в административной панели. Для точного ручного размещения используйте:

```html
<a href="#" data-murconsent-open>Настройки конфиденциальности</a>
```

Текст ручной ссылки задаёт шаблон. Автоматическая ссылка локализуется по языку текущей страницы.

## JavaScript API

### Текущее состояние

```js
window.MurConsent.getState();
```

### Проверка категории

```js
window.MurConsent.hasConsent('analytics');
window.MurConsent.hasConsent('marketing');
window.MurConsent.hasConsent('flag_counter');
```

### Открытие настроек

```js
window.MurConsent.openSettings();
```

### Конверсия

```js
window.MurConsent.trackConversion({
    sendTo: 'AW-123456789/CONVERSION_LABEL',
    eventName: 'phone_click',
    value: 1,
    currency: 'MDL'
});
```

Без действующего маркетингового согласия метод возвращает `false` и ничего не отправляет.

### Автоматическая конверсия ссылки

```html
<a href="tel:+37322123456"
   data-murconsent-conversion="phone_click"
   data-murconsent-send-to="AW-123456789/CONVERSION_LABEL">
    Позвонить
</a>
```

Дополнительно поддерживаются:

```text
data-murconsent-value
data-murconsent-currency
```

При отказе от маркетинга ссылка продолжает работать без отправки события.

### Пользовательское событие

```js
window.MurConsent.trackEvent('analytics', 'custom_event', { value: 1 });
window.MurConsent.trackEvent('marketing', 'custom_event', { value: 1 });
```

### Изменение выбора

```js
document.addEventListener('murconsent:change', function (event) {
    console.log(event.detail);
});
```

## Cookie выбора

По умолчанию используется одна first-party cookie:

```text
murconsent_preferences
```

Она содержит версию схемы, timestamp и три boolean-состояния. Имя и срок хранения настраиваются. При повреждённой cookie, неизвестной схеме или просроченном timestamp действует fail-closed: необязательные сервисы не загружаются и снова показывается баннер.

## Предварительный просмотр

Авторизованный администратор может открыть:

```text
/?murconsent_preview=1
```

Предпросмотр:

- показывает интерфейс независимо от сохранённого выбора;
- не создаёт consent cookie;
- не загружает Google или Flag Counter;
- недоступен как preview для неавторизованного посетителя.

## Ограничения

- MurConsent не способен заблокировать сторонний код, оставленный вне плагина.
- MurConsent не может прочитать содержимое удалённого GTM-контейнера.
- JavaScript не может гарантированно удалить third-party и `HttpOnly` cookies.
- Сам плагин не заменяет фактически корректную политику конфиденциальности.
- Проверка реальных Google ID и Tag Assistant выполняется на staging/production-сайте.

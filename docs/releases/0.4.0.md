# MurCMS 0.4.0

Date: 2026-09-07
Status: stable release

MurCMS `0.4.0` is the first stable release after
[`0.1.0-rc.1`](0.1.0-rc.1.md). It consolidates the current flat-file
core, administration interface, frontend template system, and plugin API into a
versioned release.

## Main changes

- Expanded admin content workflows, including bulk page operations, shared
  file upload/replace handling, breadcrumbs, media management, and safer
  backups and path validation.
- Improved frontend templates with theme schemes, custom critical/additional
  CSS, stable image dimensions, nested menus, listings, and the frontend admin
  bar.
- Added and integrated optional Redirects, MurConsent, and MurText plugins while
  retaining conditional assets and plugin-owned configuration.
- Expanded system snippets, plugin hooks, multilingual behavior, documentation,
  and regression coverage.
- Added a canonical CMS version source exposed as `MUR_CMS_VERSION` and shown
  on the existing admin Dashboard.

Plugin versions remain independent from the MurCMS core version.

Before publishing to a server, complete
[`prerelease-checklist.md`](../prerelease-checklist.md) for the target environment.
